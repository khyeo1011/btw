Print the indices of the two numbers in nums that add up to target, one per line, in either order. Every test has exactly one answer, and you can't use the same element twice.

        
btw has no arrays, so nums is a microservice: nums(i) is the element at index i. Each test adds nums and a serve that calls twoSum(n, target), where n is the length, so don't write your own serve.
